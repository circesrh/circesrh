## Projects

### 🛡️ PicatchU: AI anti-phishing awareness platform
PicatchU flags phishing and scam attempts in messages. It uses the Gemini API to spot social-engineering signals like urgency and pressure tactics. It also has a phishing simulation where users can practise recognising scams safely.

- **My part:** I designed the phishing simulation module and built the ReactJS frontend for the detection, simulation and gamified reward features.
- **Recognition:** Champion, IC Youth 2026 Hackathon Challenge (UPM) · Southeast Asia Regional Finalist, GCD4F 2026
- **Stack:** ReactJS · Gemini API
- 🔗 [Repo](https://github.com/haz1sadik/PiCatchU-AI-Digital-Safety-Platform-for-Youth)

### ♻️ Scrap2Go: End-of-life vehicle management system *(Final Year Project, in progress)*
Scrap2Go digitises Malaysia's end-of-life vehicle scrapping process for an industry client. It replaces a manual workflow that ran on WhatsApp and phone calls.

- **My part:** I own the Deregistration & Admin module. I architected it as four Spring Boot microservices (Authentication, Case, Deregistration, Notification), each with its own MySQL database, behind Spring Cloud Gateway. I'm also building the React/TypeScript admin dashboard, and I test the REST APIs with Postman to check requests, responses and how the services talk to each other.
- **Stack:** Java · Spring Boot · Spring Cloud Gateway · MySQL · Docker · React · TypeScript · Postman
- 🚧 Still in progress, so the repository isn't public yet.

### 🎓 PESKON UPM: Official convocation website
The official website for Pesta Konvokesyen (PESKON) UPM works as a digital information book, so students can see upcoming convocation events.

- **My part:** As a frontend developer, I built responsive interfaces with ReactJS, HTML, CSS and JavaScript that work across browsers and devices. I also worked with the backend developers and the design team to connect the frontend and backend.
- **Stack:** ReactJS · Vite · TailwindCSS · HTML · CSS · JavaScript
- 🔗 [Repo](https://github.com/haz1sadik/Peskon-Induk-Frontend)
